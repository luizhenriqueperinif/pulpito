Auxílio Reunião

Conectar o celular

  1. O celular precisa estar no mesmo Wi-Fi deste notebook.
  2. Abra a câmera do celular e aponte para o QR code.
  3. Toque no link que aparecer.
  4. No menu do navegador, toque em "Adicionar à tela inicial". Das próximas vezes, é só tocar no ícone.

Use "Atualizar endereço" se trocou de Wi-Fi. Aí o celular precisa ler o QR code de novo.

Controle de reserva

É o mesmo controle do celular. Use se o celular do pastor falhar no meio da reunião.
